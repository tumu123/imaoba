# imaoba.com · 缠论百科

缠中说禅《教你炒股票》108 课的**结构化词条百科**：把散落在 108 课中的概念（分型、笔、线段、中枢、背驰、买卖点）抽取为可独立索引的词条，配 108 课目录索引与资料清单。另附一个**纯前端在线画线工具**。

**纯静态站点**，零后端依赖，由 Python 脚本生成后部署。共 **146 个静态页面**。

## 画线工具

纯前端实现，**数据不上传，全部计算在浏览器本地完成**。

**算法链路**：K 线 → 包含处理（按方向取极值合并）→ 分型 → 笔（顶底交替 + 间隔过滤）→ 线段 → 中枢（三段重叠，`ZG = min(高点)`，`ZD = max(低点)`）

**已实现的决策**：
- 默认**新笔**（合并后分型索引差 ≥ 2），可切**老笔**（≥ 4）
- 以**粘贴输入**为主，不做文件上传（手机友好、兼容行情软件复制格式）
- 支持空格 / 逗号 / Tab 分隔，含或不含日期列；坏行报错但不中断解析
- 示例数据 119 根模拟 K 线，一键看到完整结构

**开发中踩过的坑（供参考）**：
1. 线段判定**不能**用「反向笔连续 ≥ 3」——笔天然交替，该条件永远不成立。正解是取反向笔高点序列找顶分型（特征序列法的工程化近似，不做包含合并，否则引入 bug）
2. 分型间距不足时应「保留更极端者」，且需多轮迭代收敛
3. 老笔标准「5 根独立 K 线」在合并后数据上几乎画不出笔，已折中为索引差 ≥ 4

**质量记录**：示例数据 119 根 → 76 合并 → 26 分型 → 13 笔 → 3 线段 → 1 中枢（`ZG = 114.30 > ZD = 113.22` 成立）。

## 本地预览

站点为纯静态，任意静态服务器均可：

```bash
python3 -m http.server 8990
```

然后访问 `http://localhost:8990/`。

## 部署

把仓库根目录下的全部内容上传到网站根目录（`wwwroot` / `public_html` / `htdocs`）。

⚠️ **不要多套一层目录**，否则首页会变成 `imaoba.com/imaoba/`。

所有链接均为根路径绝对地址（`/assets/…`、`/terms/…`），每层目录都有 `index.html`，因此放到根目录后无需任何重写规则，Apache / Nginx / IIS 均可直接访问。

上传后：
1. 访问 `https://imaoba.com/` 确认样式正常
2. 到百度搜索资源平台提交 `sitemap.xml`

### 旧链接 301（Nginx）

原 `/doc/xxx.html` 若已被搜索引擎收录，可保留权重：

```nginx
rewrite ^/doc/(.+)\.html$ /docs/$1/ permanent;
```

版本介绍

缠论资料里公认最完整的配图本，713 页、一千三百余张高清配图，由「完全分类」（徐斌）历时三年制作。

「市场哲学的数学原理」这个书名出自缠中说禅本人——他在第 72 课里说过，如果把这套理论出版，书名就可以叫《市场哲学的数学原理》。这个版本的文字忠实于博客《教你炒股票》108 课的原文；配图则把课文中提到的具体股票走势，按 1 分钟、5 分钟、30 分钟、日线、周线等不同级别从行情软件里复原并统一格式保存，难理解的课文配图可达五十张以上。

该手册 2013 年初稿、2015 年修订，正式出版物于 2019 年由四川民族出版社出版，徐斌编著（ISBN 9787540982348）。本文件为 2017 年的网络流传版本。

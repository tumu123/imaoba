版本介绍

付上金编著，中国宇航出版社 2014 年 8 月出版（ISBN 978-7-5159-0742-0）。针对原著语言艰涩、结构松散的问题，对缠论框架做了一次系统性重构。

全书共 21 章，从顶底分型、笔、线段、走势类型、走势中枢，一路讲到均线系统、背驰与三类买卖点，把判定规则逐条写明，并专门解析了走势中枢的多义性、相关数学定理与走势连接的分解逻辑。

书中还谈到资金管理、选股流程与风险控制，并提出用三个相互独立的系统共同研判走势。附录另附「缠精准笔」操作工具。

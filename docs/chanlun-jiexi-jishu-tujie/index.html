版本介绍

江南小隐著，中国宇航出版社 2012 年 7 月出版（ISBN 978-7-5159-0235-7）。在系统梳理 108 课的同时，也把理论本身的矛盾摆到台面上讲。

全书分形态学、动力学、操作技巧、操作心态四块，把 K 线包含处理、分型、笔、线段、走势中枢这些概念串成一条线，再用通俗的图解讲趋势背驰与盘整背驰，并总结了防狼术、高效买入法、中阴阶段操作等技巧。

这本书的特别之处在于不盲从：作者指出缠中说禅在定义走势中枢时存在循环定义的问题，也讨论了「是否有必要用高等数学来解构股市」，并分析了理论中零碎、前后不一致的地方。想跳出「千人千缠」的境地，这类批评性解读值得一读。2019 年另出增订本。

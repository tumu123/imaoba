第 23 课 · 笔、线段与中枢

结合律与走势分解

最后更新 2026年11月25日

走势结合律，保证分解结果可比较。

本课要解决的问题　这一课看起来最像数学，但它解决的是一个很实际的问题：从不同位置开始分解，结果还能不能互相对照。

核心论点
走势结合律：走势单元的连接满足结合律，保证分解结果可以互相比较、重排。

关键要点

  • (A + B) + C = A + (B + C)，走势单元的连接顺序不影响整体结构。
  • 结合律是「分解结果唯一」的数学基础之一。
  • 它保证不同起点的分解可以对齐比较。
  • 实务意义：可以从任意明确的起点开始分解，结果自洽。

推导与边界

  • 走势连接满足结合律：(A+B)+C 与 A+(B+C) 描述同一段结构，只是分组方式不同。
  • 不满足交换律：顺序有意义，A+B 与 B+A 不是同一段走势。
  • 结合律是分解唯一的数学基础之一，它保证不同起点的分解可以对齐到同一组段。
  • 实务意义是从任意明确起点开始分解，结果都自洽，不必强求找到所谓绝对起点。
  • 边界条件：结合律只在同级别分解下成立，跨级别混用会直接破坏它。
  • 用途：两套分解看似不同时，先用结合律检查是否只是分组差异，而不是真的矛盾。
  • 对齐之后仍不一致，问题多半在比较对象而非分解本身——先查两段是否同级别同类型。
  • 实用推论是：分解既可以向前推也可以向后验——从当前结构往回推得到的段，与当初正向分解的段应当吻合，不吻合说明中间有一步画错了。
  • 结合律还能反向用：怀疑一套分解有问题时，换一种分组方式重排，若重排后结论改变，说明原来的分组跨了级别。

判断清单

两套分解看似冲突时，按顺序验：
① 段的数量是否相同？不同 → 可能真的分歧，回到第 22 课处理。
② 段数相同但切点不同 → 检查是否只是分组差异（结合律范围内），对齐后应完全一致。
③ 段数相同、切点相同、结论不同 → 检查比较的两段是否同级别同类型，多半是比较对象错了。

常见疑问

结合律能用来合并不同级别的段吗？

不能。它只保证同级别分组方式不影响结果，跨级别合并等于偷偷改变了分解粒度。

为什么顺序不能交换？

因为走势有方向。先涨后跌与先跌后涨是两段完全不同的结构，交换后买卖点的位置全变。

本课涉及的概念

  • 同级别分解把任意复杂走势，按同一级别拆解成可互相比较的走势单元。它是判断背驰、定位买卖点的必要前提。
  • 走势类型市场走势只有三种类型：上涨、下跌、盘整。任何走势都可以被唯一地分解为走势类型的连接。

一句话总结

结合律保证同级别分解可对齐，交换律不成立；跨级别混用会破坏它。

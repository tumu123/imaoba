第 98 课 · 实战与哲学

与其他技术分析的关系

最后更新 2026年11月25日

道氏、波浪、均线、形态学与缠论的四项对照，以及混用的后果。

本课要解决的问题　这一课不做优劣比较，做能力边界比较：道氏、波浪、均线、形态学各自能回答什么、不能回答什么，以及混用时会发生什么。

核心论点
与其他技术分析的关系：与道氏、波浪、均线体系对照。

关键要点

  • 与道氏理论：都强调趋势与级别，但缠论的结构定义更严格。
  • 与波浪理论：都做走势分类，但缠论要求分解唯一、可验证。
  • 与均线系统：均线提供趋势参考，不提供买卖点参照。
  • 缠论的差异点在于「级别递归 + 力度比较」的组合。

推导与边界

  • 比较的维度要先固定，否则会变成门派之争。用四项：如何定义一段走势、如何确定级别、如何判定转折、结论是否可复现。四项里任何一项答不出，该体系就无法参与买卖点判定。
  • 道氏：用高低点序列定义趋势，级别靠「主要、次要、日间」的经验划分，转折靠高低点被破坏。强项是方向判断稳，弱项是级别与转折点给不出精确位置——它回答「往哪走」，不回答「在哪买」。
  • 波浪：用浪型结构定义走势，级别靠嵌套计数，转折靠浪型完成。问题在计数不唯一：同一段走势可以有多条合法数法，两人可以数出不同起点，这与「同一规则下分解唯一」直接冲突。
  • 均线与形态学：均线是价格的平滑，形态是价格的外形。两者都不定义「一段走势」，因此都无法回答「这一段是什么级别」——它们提供观察角度，不提供结构分解。
  • 缠论与它们的差别集中在两点：级别由递归定义（不从时间周期来）、分解结果唯一（同一规则下只有一种画法）。这两点是它能被程序化的原因，也是它与上述体系不能直接互译的原因。
  • 混用的后果要说清：用波浪数浪确定级别，再用缠论找买卖点，会得到「级别来自一个不可复现的分解」的结论——形式上完整，实际上无法复盘。混用不是禁止，前提是先固定级别来源，且只用一个来源。

四项对照

四项对照（行：体系；列：定义走势 / 定级别 / 判转折 / 可否复现）：
道氏：高低点序列 / 经验划分 / 高低点破坏 / 大致可复现
波浪：浪型结构 / 嵌套计数 / 浪型完成 / 不可复现（数法不唯一）
均线：不定义 / 不能 / 均线交叉 / 可复现但非结构
形态学：不定义 / 不能 / 形态完成 / 主观性较强
缠论：走势类型 / 递归构成 / 买卖点 / 同口径下唯一
读法：只有最后一列与第二列同时成立，才能支撑买卖点判定。

常见疑问

能不能用波浪辅助判断，比如数到第五浪就准备卖？

可以当观察提示，不能当判据。第五浪的结束时点依赖数法，而数法不唯一；同样叫「第五浪」，两个人可以数出不同的起点。用它提示「这段可能接近尾声」是合理的，用它决定卖出位置则不可复现。

均线真的一点用都没有吗？

有用，但不能进判定。均线在多头发散状态下确实常与趋势同向，这一点可以用作事后描述；但它给不出「这一段是什么级别」，也就无法参与买卖点判定。均线与 MACD 测的是同一个量（速度），两者不构成独立证据。

本课涉及的概念

  • 走势类型市场走势只有三种类型：上涨、下跌、盘整。任何走势都可以被唯一地分解为走势类型的连接。
  • 区间套与级别用低级别的背驰来确认高级别背驰的方法，可把买卖点逐步收敛到更精确的区间。级别是缠论区别于其他技术分析的根本。
  • 同级别分解把任意复杂走势，按同一级别拆解成可互相比较的走势单元。它是判断背驰、定位买卖点的必要前提。

一句话总结

四项维度（定义走势、定级别、判转折、可否复现）里，只有缠论同时满足后两项；混用的前提是先固定级别来源且只用一处。

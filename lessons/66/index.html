第 66 课 · 实战与哲学

走势类型的完备性

最后更新 2026年11月25日

三种走势类型覆盖所有可能。

本课要解决的问题　第 51 课讲了三种类型分别是什么，这一课回答更难的问题：为什么恰好是三种——少一种会漏，多一种会重，理由必须能摆出来。

核心论点
走势类型的完备性：上涨、下跌、盘整三种类型覆盖所有可能，构成完备分类。

关键要点

  • 分类依据是中枢排列，而非涨跌幅或时间。
  • 任一已完成走势必属且仅属其中一类。
  • 完备性保证了后续推导不会遗漏情形。
  • 分类完成是力度比较与买卖点判定的前置。

推导与边界

  • 完备性要同时证明两件事：互斥（任一走势只能属于一类）与穷尽（任一走势必属于某一类）。缺一个，分类就不能用来推导。
  • 分类依据只有一条：同级别中枢的数量与排列关系。不用涨跌幅、不用时间、不用成交量，这三样都不是结构属性。
  • 穷尽的理由是一次二分：一段走势里的中枢，要么只有一个，要么两个及以上；两个及以上时，相邻中枢的区间要么重叠，要么不重叠。这个二分把所有情形分完。
  • 互斥的理由是判据唯一：三类由同一组判据界定，判定顺序固定，任一段走势在判定树上只有一条路径，不可能同时落入两类。
  • 扩展为什么不算第四类：扩展的本质是区间推宽到满足更大级别的条件，级别升一级之后，它在新级别上仍是盘整。单列会让分类在同一级别内不互斥。
  • 完备性是后面两处推导的地基：67 课的一买证明先要假定趋势有明确定义，72 课的必完美证明先要假定任何走势都能归入某一类。
  • 完备性不保证容易判定：边界处要等结构完成才能分类。这不是缺陷——完备性是针对已完成的走势说的。

判定树

判定树，自上而下，一步一分支：
第 1 问：这段走势里有几个同级别中枢？
　0 个 → 结构未完成，暂不分类（不是第四类）
　1 个 → 盘整
　≥2 个 → 进入第 2 问
第 2 问：相邻中枢的区间是否重叠？
　全部不重叠且同向 → 趋势（上涨或下跌）
　存在重叠 → 扩展，级别升一级，回到第 1 问重新判定
每一步都有唯一出口：这就是互斥；每个已完成的走势都能走到底：这就是穷尽。

常见疑问

0 个中枢的情况算不算完备性的漏洞？

不算。完备性针对已完成的走势；一个中枢都没有，说明走势还在生长，尚未进入可分类状态。把它硬塞进三类中的任何一类，反而会破坏互斥。

为什么不能按涨跌幅分类，非要绕到中枢上？

因为涨跌幅是结果不是结构。同样跌 30%，可能是趋势的第一段，也可能是盘整的中轴；按幅度分类，同一段走势会因为取的时间窗口不同而得到不同答案，可复现性就没了。

本课涉及的概念

  • 走势类型市场走势只有三种类型：上涨、下跌、盘整。任何走势都可以被唯一地分解为走势类型的连接。
  • 中枢连续三个次级别走势的重叠区间。中枢的级别由构成它的次级别走势决定，是整个理论的核心与买卖点的坐标系。
  • 同级别分解把任意复杂走势，按同一级别拆解成可互相比较的走势单元。它是判断背驰、定位买卖点的必要前提。

一句话总结

完备性 = 互斥 + 穷尽，依据只有中枢数量与区间关系；扩展不是第四类而是升级后的盘整；0 个中枢属于未完成，不构成漏洞。

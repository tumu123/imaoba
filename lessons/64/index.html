第 64 课 · 实战与哲学

中枢的数学定义

最后更新 2026年11月25日

区间重叠的严格表述。

本课要解决的问题　中枢的定义只有一行，却是全站被引用最多的判据。这一课把那一行拆开：每个符号管什么、边界怎么算、哪些东西不能塞进来。

核心论点
中枢的数学定义：连续三个次级别走势区间重叠部分的严格表述。

关键要点

  • 取三段的高点最小值 ZG，低点最大值 ZD。
  • ZG > ZD 才构成中枢，否则说明没有真实重叠。
  • 定义基于区间运算，与形态、时间无关。
  • 严格的定义使中枢可以由程序自动识别。

推导与边界

  • 定义：连续三段次级别走势类型，取第一段与第三段的高点最小值 ZG、低点最大值 ZD；ZG > ZD 时，区间 [ZD, ZG] 构成中枢。
  • 三个关键词要拆开：连续（中间不能缺段）、次级别走势类型（不是笔，也不是任意三根 K 线）、重叠（区间交集非空）。
  • 为什么取一三段而不取三段的极值：第二段是回抽段，它的高低点必然落在一三段之间；用一三段判定与用三段判定等价，但计算更简洁、更少歧义。
  • ZG = ZD 是临界，不构成中枢：重叠退化为一个点，说明多空只在某个价位接触过一次，没有形成反复争夺的区间。
  • 定义与形态、时间无关：不看涨跌幅、不看持续几天、不看成交量。把这些因素塞进中枢判定，定义立刻失去可复现性。
  • 严格定义的价值在于可编码：区间运算能交给程序完成。第 87 课的程序化之所以可行，起点就是这一行。
  • 中枢方向由进入段决定：向上进入的是上涨中枢，向下进入的是下跌中枢。方向不属于定义，但影响后续三买的判定。

结构示例（示意性构造）

数值演算：
三段次级别走势：① 10.00 → 13.00（高 13.00，低 10.00）；② 13.00 → 11.20；③ 11.20 → 14.50（高 14.50，低 11.20）。
ZG = min(13.00, 14.50) = 13.00；ZD = max(10.00, 11.20) = 11.20。
ZG 13.00 > ZD 11.20 → 中枢区间 [11.20, 13.00]。
变体一：第三段只到 12.80 → ZG = 12.80，区间收窄为 [11.20, 12.80]，仍成立。
变体二：第三段低点回到 10.50，且高点 11.00 → ZG = min(13.00, 11.00) = 11.00，ZD = max(10.00, 10.50) = 10.50，区间 [10.50, 11.00]，重叠大幅收窄但仍成立。
变体三：第三段高点 10.80、低点 10.20 → ZG = 10.80 低于 ZD = 10.20？不成立，实际 ZG = 10.80、ZD = 10.20 时 ZG > ZD 仍成立；要退化必须让三段区间完全没有公共交集，此时 ZG ≤ ZD，中枢不构成。

常见疑问

为什么是三段而不是两段？

两段的重叠不足以表达「反复争夺」。三段才构成有效的中枢区间。

中枢区间要不要把上下影线算进去？

用最高价与最低价，不另设规则。定义只说高点、低点，不区分实体与影线；要改就必须全站统一改，不能一处用影线、一处用实体，否则同一段走势会算出两个中枢。

中枢形成之后区间会变吗？

会。延伸与扩展都会改变边界（第 16、53 课）。变的是区间数值，不变的是构成方式——仍然是三段次级别走势的重叠，这一点在任何时候都不改。

本课涉及的概念

  • 中枢连续三个次级别走势的重叠区间。中枢的级别由构成它的次级别走势决定，是整个理论的核心与买卖点的坐标系。
  • 区间套与级别用低级别的背驰来确认高级别背驰的方法，可把买卖点逐步收敛到更精确的区间。级别是缠论区别于其他技术分析的根本。
  • 线段由至少三笔构成、有明确方向的走势单元，是中枢的构件。线段划分是缠论实操中争议最大的环节。

一句话总结

中枢 = 连续三段次级别走势类型的区间交集，ZG 取一三段高点最小值、ZD 取低点最大值，ZG > ZD 才成立；与形态时间无关。

第 107 课 · 实战与哲学

总结：一套完整的操作体系

最后更新 2026年11月25日

七个环节的输入与输出，以及断在哪一环会出现什么症状。

本课要解决的问题　把七个环节串起来只是目录。真正有用的是反过来用：从症状反推断在哪一环。这一课给一张诊断表，并说明为什么可复现性是这套体系与经验总结的分界。

核心论点
总结：一套完整的操作体系，把前面的内容串成可执行的流程。

关键要点

  • 流程：定级别 → 画结构 → 分走势类型 → 比力度 → 找买卖点 → 设止损 → 控仓位。
  • 每个环节都有明确的输入与输出，不留主观空间。
  • 体系的完整性来自各环节全部基于同一套定义。
  • 可复现性是这个体系区别于经验总结的根本。

推导与边界

  • 七个环节与各自的输出：定级别（操作级别）→ 画结构（笔、线段、中枢）→ 分类型（趋势或盘整）→ 比力度（是否背驰）→ 找买卖点（类别与位置）→ 设止损（结构破坏位）→ 控仓位（股数与上限）。
  • 环节之间是单向依赖：后一环的输入必须是前一环的输出。跳环不会让结果更好，只会让结果无法追溯——而无法追溯的结论，对了也不知道为什么对。
  • 断点一（级别未定）：症状是「换个周期结论就变」「说不清现在是哪个级别」。此时后面六环全部无效，因为坐标系还没建立。回第 21、65 课。
  • 断点二（结构画错）：症状是「笔数反复变」「同一个中枢两个人画出不同区间」。多由包含处理方向不固定、或新笔老笔混用导致。回第 9–11 课。
  • 断点三（力度比较不合规）：症状是「背驰到处都有」「每次下跌都能找到背驰」。多由四同条件不满足导致——不同级别、不同方向、或其中一段尚未完成。回第 30、70 课。
  • 断点四（止损与仓位脱节）：症状是「判断对还亏钱」「止损总被正常波动打掉」。止损位往往没错，错在仓位用了错误的距离去算。回第 45、46 课。
  • 断点五（退出条件未写）：症状是「不知道什么时候该走」「拿着不动变成长期被套」。入场条件写得再细，没有退出条件也不构成完整计划。回第 74、93 课。
  • 可复现性是这套体系区别于经验总结的地方：同一份数据、同一套口径，两次运行应得到同样的七环输出。做不到，说明某一环的口径没有固定，而不是市场变了。

断点诊断表

断点诊断表（症状 → 断点 → 回查课号）：
「换周期结论就变」→ 级别未定 → 第 21、65 课
「笔数反复变」→ 结构画错 → 第 9–11 课
「背驰到处都是」→ 力度比较不合规 → 第 30、70 课
「判断对还亏钱」→ 止损与仓位脱节 → 第 45、46 课
「不知道什么时候走」→ 退出条件未写 → 第 74、93 课
「说得清但做不出」→ 预案未落成三态 → 第 93 课

常见疑问

七个环节必须全做吗？少做一环会怎样？

少任何一环，后面都失去输入。最常见的「少做」是跳过级别直接找买卖点，结果是买卖点成立但不知道能持多久、止损该放多远——判断没错，操作全错。

这套流程能不能简化成三条？

可以简化表述，不能简化执行：定级别、定位置、定退出。三条覆盖七环，但每一条内部仍要走完对应环节，否则「定」只是嘴上定。

本课涉及的概念

  • 区间套与级别用低级别的背驰来确认高级别背驰的方法，可把买卖点逐步收敛到更精确的区间。级别是缠论区别于其他技术分析的根本。
  • 同级别分解把任意复杂走势，按同一级别拆解成可互相比较的走势单元。它是判断背驰、定位买卖点的必要前提。
  • 背驰走势方向不变但力度衰减的现象，是比较同级别、同类型走势之间力度得出的结论。背驰是趋势终结的必要条件。
  • 三类买卖点缠论的完整操作体系：第一类（趋势背驰）、第二类（次级回抽不破）、第三类（离开中枢后回抽不回中枢）。本页为总览，三点各自另有独立词条。

一句话总结

七环单向依赖，断点可由症状反查：换周期结论变、笔数变、背驰到处有、判断对还亏、说不出何时走，分别对应五处断点。
